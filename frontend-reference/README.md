# Frontend reference

Snapshot of the original starter frontend, kept for reference only.

**These files are not part of the running application.** The live templates
live in `public/` and `src/includes/`, where the markup has been removed so the
frontend can be built from scratch.

| Reference file | Corresponds to |
| --- | --- |
| `public/index.php` | `public/index.php` |
| `public/reserve.php` | `public/reserve.php` |
| `public/css/style.css` | `public/css/style.css` |
| `src/includes/header.php` | `src/includes/header.php` |
| `src/includes/footer.php` | `src/includes/footer.php` |

The backend — database access, validation, CSRF handling, and the queries that
feed the templates — is unchanged and still lives in `src/` and at the top of
each page in `public/`.
