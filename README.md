# Maridadi Eat

A restaurant website in plain PHP and MySQL — menu, pre-ordering, payment,
order tracking, table booking, and a kitchen screen. No framework, no
Composer, no npm, no build step.

**The documentation lives in [`docs/`](docs/):**

## Running it

```bash
php -S localhost:8000
```

Then open <http://localhost:8000>. If the menu says it is unavailable, the
database is not reachable — see [docs/README.md](docs/README.md).
